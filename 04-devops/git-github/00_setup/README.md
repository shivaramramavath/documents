# 00 — Setup

Everything you need before you start using Git: installing it, configuring your identity, and running your first commands.

## In this section

| File                 | Covers                                                                                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getting-started.md` | Installing Git, setting your name/email (`git config`), and the first commands you'll run (`git init`, `git status`, `git add`, `git commit`) to confirm everything works |

## Why this comes first

Git won't let you commit without a configured name and email, and you can't practice anything else until Git is actually installed and responding. This section gets you from "nothing installed" to "made my first commit" — everything after this assumes that's done.

## What you should be able to do after this section

- Run `git --version` and see a version number
- Run `git config --global user.name` / `user.email` and see your identity
- Create a new repository and make a commit in it
